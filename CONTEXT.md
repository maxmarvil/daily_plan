# Daily Plan

Контекст: минималистичная записная книжка для ежедневных задач, вызываемая
глобальной горячей клавишей. Задачи привязаны к дате, не имеют заголовков,
не удаляются; текст правится только в «свой» день, а комментировать и отмечать
выполненными можно задачи любого дня.

## Language

**Task (Задача)**:
Один пункт на день — многострочный текст, созданный в конкретную дату.
Нумерация — порядок создания внутри дня (`position`). Текст задач текущего дня
редактируется; задачи прошлых дней — только комментируются и отмечаются
выполненными.
_Avoid_: note, todo item, entry

**Done (Выполнено)**:
Состояние задачи (`tasks.is_done`), принадлежащее **оригиналу**. Любая запись
задачи в календаре — оригинал или перенос — отображает и переключает одно и то
же состояние. Отметить выполненной можно задачу любого дня, включая прошлые;
выполненная задача не скрывается и не удаляется.
_Avoid_: complete, close, archive

**Day (День)**:
Календарная дата в локальном времени, к которой привязаны задачи. Формат
хранения — `YYYY-MM-DD`. В интерфейсе день отображается как группирующая
метка (режим «Месяц») или ячейка (режим «Год»).
_Avoid_: session, page

**Transfer / Link (Перенос / Ссылка)**:
Запись в дне B, указывающая на задачу из дня A. Не дублирует текст; визуально
рендерится как однострочный предпросмотр оригинала (переводы строк схлопнуты)
с переходом к нему. Строка-перенос отражает и переключает **done оригинала**.
Одну и ту же задачу нельзя перенести в один день дважды; перенести можно в любой
день, в том числе в другой месяц.
_Avoid_: copy, duplicate, move (move implies the original leaves)

**Original (Оригинал)**:
Задача, на которую ссылается перенос. Носитель `is_done`: перенос показывает
и переключает состояние оригинала. Комментарии всегда привязаны к оригиналу,
а не к отдельным переносам.
_Avoid_: source task (too technical)

**Comment (Комментарий)**:
Текстовая запись, добавленная к задаче. Единая лента для оригинала и всех
его переносов. Комментарии разрешены к задачам любого дня.
_Avoid_: reply, note, message

**Capture (Quick-capture)**:
Компактное окно поверх всех окон для быстрого создания/редактирования задач
текущего дня. Вызывается глобальной комбинацией клавиш.
_Avoid_: main window, editor

**Calendar (Календарь)**:
Отдельный экран с двумя режимами: «Год» (сетка 3 колонки × 4 ряда с тепловой
картой количества задач) и «Месяц» (список задач по дням: дни по убыванию даты,
внутри дня — по `position`).
_Avoid_: planner, scheduler

**Shortcut (Комбинация)**:
Глобальная горячая клавиша: «Вызов окна задач» (по умолчанию `CmdOrCtrl+Shift+D`)
или «Новая задача» (по умолчанию `CmdOrCtrl+Shift+N`). Обе задаются в настройках,
хранятся в таблице `settings` и применяются при каждом запуске.
_Avoid_: hotkey (colloquial)

## Invariants

- Задачи не удаляются: `DELETE` из `tasks` запрещён триггером (миграция `0008`).
- «Свой день» — правило UI: текст правится только у задач текущего дня; backend
  его не проверяет (весь CRUD идёт из JS через `tauri-plugin-sql`). Комментировать
  и переключать `is_done` можно задаче любого дня.
- `is_done` — свойство оригинала: перенос показывает и переключает состояние
  оригинала, а не своё (см. **Done**).
- Комментарии привязаны к оригиналу задачи, даже если добавлены через перенос;
  комментарий к записи-переносу запрещён триггером.
- Перенос — ссылка, а не копия текста. Перенос-переноса запрещён (`source_id` не
  может указывать на перенос), `source_id <> id`, одна задача не переносится в
  один и тот же день дважды.
- Одна задача в день — одна `position`: `UNIQUE(day, position)`, `position ≥ 1`
  (миграция `0008`).
- Инварианты схемы (`0008`): `day` в формате `YYYY-MM-DD` и календарно
  валиден (`date(day) = day`); у обычной задачи
  непустой `text`, у переноса `text = ''`; `is_done ∈ {0, 1}`; `day`,
  `created_at` и `source_id` неизменяемы после вставки.
- В режиме «Год» активностью дня считается любая задача, включая выполненные
  и переносы.
