# Changelog

Все заметные изменения проекта Daily Plan. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.2.0] — 2026-11-03

### Added

- **done-состояние задач**: задача отмечается выполненной/возвращается в работу
  в capture-окне и календаре; у переноса done отражает состояние оригинала
  (миграция `0007`, колонка `tasks.is_done`).
- **Миграция `0008` — инварианты данных на уровне БД**: `UNIQUE(day, position)`,
  проверка формата `day`, непустого текста у обычной задачи и пустого у переноса,
  запрет self-reference и «переноса переноса», `is_done ∈ {0, 1}`,
  неизменяемость `day`/`created_at`/`source_id`, запрет `DELETE` задач,
  комментарии только к оригиналам. Схема больше не держится на соглашении.
- **Перенос задачи в другой месяц**: в календаре можно перейти в соседний месяц
  и перенести задачу туда, не дожидаясь нужной даты.
- **Бейджи комментариев и переносов в capture-окне**: переносы показываются
  с текстом оригинала, а не пустыми строками; у строк видны счётчики комментариев.
- **Индикатор «у оригинала есть переносы»** в календаре.
- **Ежедневный авто-бэкап БД**: снимок при запуске, если за сегодня его ещё
  нет, через `VACUUM INTO`
  (безопасно для WAL) в каталог `backups/` рядом с данными приложения,
  хранятся 7 последних копий (`prepare_backup` / `prune_backups`).
- **CI** (`.github/workflows/ci.yml`): фронтенд — `npm ci`, `npm test`,
  `npm run check` (svelte-check), `npm run build`; Rust — `cargo fmt --check`,
  `cargo clippy --all-targets -- -D warnings`, `cargo test`.
- **Typecheck фронтенда**: `svelte-check` + `src/vite-env.d.ts` (лечит TS2882
  на импорте `./app.css`), TypeScript 6.x; скрипты `npm run check` /
  `check:watch` / `rust:lint`.
- **Rust-тесты** на валидацию даты бэкапа и round-trip канонической строки
  глобального шортката.
- **`.editorconfig`** и `svelte.config.js` (vitePreprocess) — единые отступы
  и отсутствие предупреждения vite-plugin-svelte.
- **Оформление устанавливаемого приложения (macOS)**: метаданные `bundle`
  (категория Productivity, минимальная macOS 12, описания, copyright),
  `npm run release`, `scripts/build-macos.sh` (проверка версий + `.app`/`.dmg`
  и запасной `.zip`), фолбэк-сборка DMG без Finder-стилизации
  (`scripts/make-dmg.sh`, через hdiutil), инструкция `docs/release.md`
  (подпись Developer ID,
  нотаризация, universal-бинарь, CI).

### Changed

- **`scripts/rollback.sh` стал безопасным**: проверка, что приложение
  закрыто (обход `FORCE=1`), preflight всех `.down.sql` до изменений,
  бэкап через `sqlite3 .backup` вместо `cp` (не теряет закоммиченные данные
  из WAL) с `integrity_check`, каждая down-миграция + удаление строки
  `_sqlx_migrations` — в одной транзакции; внятные сообщения об ошибках.
- **Запрет закрытия главного окна**: кнопка закрытия отключена, а
  `CloseRequested` перехватывается и скрывает capture вместо безвозвратного
  закрытия; вернуть его можно шорткатом или из трея.
- **Синхронизация capture-окна**: обновление по `tasks-changed`,
  перепроверка «сегодня» при показе (`capture-shown`), чтобы окно не
  показывало устаревший день.
- **a11y**: строки-кнопки заменены на настоящие `<button>` без вложенной
  интерактивности, `:focus-visible` для действий, `aria-label`/`aria-pressed`
  для кнопок done/переноса/комментариев, ячейки года получили подписи.
- **Чистка зависимостей и прав**: убраны неиспользуемый `plugin-opener`
  и лишние permissions; CSP дополнен `connect-src ipc: http://ipc.localhost`.
- **Календарь, режим «Год»**: крупнее номера дней (`clamp(12px, 2.2vw, 20px)` вместо
  8–13 px), уменьшены отступы между днями и увеличен отступ между месяцами (+15 px); минимальная ширина года — 657 px, при более узком
  окне появляется горизонтальный скролл (минимальная ширина окна календаря снижена
  до 360 px), шапка календаря переносится.
- **Документация приведена к коду**: CONCEPT/CONTEXT/README/AGENTS
  (сетка календаря 3×4, модель `is_done`, `settings`, второй шорткат,
  `$N`-параметры sqlx, команды бэкапа).

### Fixed

- **Гонки сохранения в capture-окне**: guard от повторной отправки
  (`commitDraft` / `saveEdit` / `submitComment`), захват текущего
  редактирования — дубли задач и «потерянные» правки из-за двойного Enter.
- **Ошибки БД больше не проглатываются**: ошибки `getDb()` и запросов
  доходят до пользователя видимым состоянием ошибки, а не тихим отказом.
- **Регрессия отображения шорткатов**: сохранённые комбинации снова
  показываются канонически (`Alt+Shift+N`), а не `shift alt KeyN`;
  состояние шортката в настройках честно отражает отказ регистрации.
- **Гонки открытия окон**: повторный вызов команд переиспользует уже
  открытое окно и поднимает его наверх.
- **`done` у переносов и прошлых дней**: поведение определено и одинаково
  в capture, календаре и окне задачи.
