# Daily Plan

Компактная записная книжка для быстрых задач на день. Концепция — в [CONCEPT.md](./CONCEPT.md).

Стек: **Tauri v2 + Rust**, фронтенд **Svelte 5 + Vite**, БД **SQLite** (`tauri-plugin-sql`).

## Запуск (dev)

```bash
npm ci
npm run tauri dev
```

## Проверки

```bash
npm test          # vitest (чистые хелперы)
npm run check     # svelte-check (TypeScript + Svelte)
npm run build     # vite build
(cd src-tauri && cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test)
```

Те же проверки гоняет CI: `.github/workflows/ci.yml`.

## Управление

- `Cmd+Shift+D` (глобально, по умолчанию) — показать/скрыть окно задач.
- `Cmd+Shift+N` (глобально, по умолчанию) — сразу открыть ввод новой задачи.
  Обе комбинации настраиваются в окне настроек (шестерёнка в шапке), сохраняются
  в таблице `settings` и применяются при каждом запуске.
- Кнопка `+` — новая задача текущего дня (Enter — сохранить, Shift+Enter — перенос строки).
- Клик по задаче — inline-редактирование (текст правится только у задач текущего дня).
- `✓` / `↩` — отметить задачу выполненной / вернуть в работу. Доступно задачам
  любого дня; у переноса переключает состояние оригинала.
- `💬` — бейдж комментариев; кнопка у задачи открывает окно задачи (общая лента
  оригинала для переноса).
- `↪` в режиме «Месяц» — перенос задачи. Пикер листает месяцы, уже перенесённые
  дни недоступны; после переноса календарь переходит на месяц цели.
- `‹` / `›` у заголовка календаря — навигация по месяцам/годам; «Год» / «Месяц» —
  режимы.
- Трей-меню: «Новая задача», «Календарь», «Настройки», «Выход».
- `Esc` — отменить редактор/черновик; повторный `Esc` скрывает окно. Окна задач
  закрываются по `Esc` (и переоткрываются). Скрытие окна шорткатом/треем не теряет
  набранное: черновик новой задачи сохраняется, а незавершённая inline-правка
  сохраняется при следующем показе окна.

Окно поверх всех (`alwaysOnTop`), при старте скрыто, приложение работает в режиме
агента (без иконки в Dock, `ActivationPolicy::Accessory`). У главного окна
отключена кнопка закрытия (`closable: false`), а `CloseRequested` дополнительно
перехватывается и скрывает окно, поэтому capture не теряется: вернуть его можно
шорткатом или пунктом трея.

## Данные и бэкап

- Данные: `~/Library/Application Support/app.dailyplan.desktop/daily-plan.db`
  (`app_config_dir`; рядом `-wal`/`-shm`).
- При старте главного окна раз в день создаётся копия через `VACUUM INTO`:
  `~/Library/Application Support/app.dailyplan.desktop/backups/daily-plan-YYYY-MM-DD.db`.
  Хранятся последние 7 бэкапов, старые удаляются.
- Ручной откат миграций: `scripts/rollback.sh <target_version>`. Скрипт требует
  закрытого приложения, проверяет наличие всех down-файлов (preflight), снимает
  копию через `sqlite3 .backup` и выполняет каждую down-миграцию в отдельной
  транзакции. При сбое посередине БД останется частично откаченной — для
  восстановления есть бэкап (путь печатается в конце).
- Требуется `sqlite3` ≥ 3.35 (down `0007` использует `DROP COLUMN`; на macOS 12+
  системный `sqlite3` подходит).
- `0008` создаёт `UNIQUE(day, position)`. На «грязной» БД с дублями миграция
  не применится и приложение не запустится — проверьте данные или восстановите
  бэкап (миграция сознательно не правит историю автоматически).
- **Осторожно:** откат до 5 или ниже удаляет таблицу `settings` (сохранённые
  комбинации), откат до 6 — колонку `is_done` и триггеры `0008`. После
  перезапуска `tauri-plugin-sql` снова применит откатанные up-миграции. Откат
  до 0 удаляет все задачи и комментарии.

## Структура

- `src/` — Svelte-фронтенд (capture, календарь, просмотр задачи, настройки).
- `src/lib/` — общие хелперы: даты, шорткаты, запросы к задачам (`tasks.ts`).
- `src-tauri/` — Rust: миграции SQLite, глобальные шорткаты, политика окон, бэкапы.
- `src-tauri/migrations/` — схема БД: пары `NNNN_name.up.sql` / `.down.sql`.
- БД: `daily-plan.db` в `app_config_dir` (см. «Данные и бэкап»).

## Миграции

`tauri-plugin-sql` выполняет только Up при старте приложения.

Новая миграция: создать пару `0009_name.up.sql` / `0009_name.down.sql`
в `src-tauri/migrations/` и добавить строку в `MIGRATIONS` в
`src-tauri/src/lib.rs` (up встраивается `include_str!`).

Схемные инварианты (формат `day`, `UNIQUE(day, position)`, запрет `DELETE`,
правила `text`/`source_id` и т.п.) закреплены триггерами и индексами в `0008`;
правило «текст правится только в свой день» остаётся UI-правилом.

Ручной откат — `scripts/rollback.sh <target_version>` (см. «Данные и бэкап»).

## Сборка и установка (macOS)

Подробная инструкция — [docs/release.md](./docs/release.md). Кратко:

```bash
npm ci
npm run tauri build      # .app + .dmg для текущей архитектуры
npm run release          # то же самое
scripts/build-macos.sh   # проверки (check/test) + сборка + пути артефактов
scripts/make-dmg.sh      # DMG напрямую через hdiutil (если нет Automation у Finder)
```

Артефакты:

- `src-tauri/target/release/bundle/macos/Daily Plan.app`
- `src-tauri/target/release/bundle/dmg/Daily Plan_<version>_<arch>.dmg`
- `src-tauri/target/release/bundle/zip/Daily Plan_<version>_<arch>.zip`

Установка: открыть `.dmg` → перетащить **Daily Plan** в **Applications**.
Данные (`~/Library/Application Support/app.dailyplan.desktop/`) при переустановке
и обновлении сохраняются; бэкапы — в `backups/` (см. «Данные и бэкап»).

Для распространения без предупреждений Gatekeeper нужны подпись **Developer ID
Application** и нотаризация Apple — как это настроить, написано в
[docs/release.md](./docs/release.md). Иконки лежат в `src-tauri/icons/` и
подключены в `bundle.icon`; при смене иконки: `npm run tauri icon app-icon.png`.
